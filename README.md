# Поиск Яндекс

Добавляет Яндекс к поисковым системам Firefox. В адресной строке движок вызывается ключевым словом `@yandex`.

Выделенный текст и картинку на странице можно отправить в Яндекс из контекстного меню.

## Что нового

### 1.1.0

- Поиск выделенного текста из контекстного меню
- Поиск по картинке из контекстного меню
- Поиск открывается на ya.ru вместо yandex.ru, чтобы убрать лишние редиректы
