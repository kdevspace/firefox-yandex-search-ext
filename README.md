# Поиск Яндекс

Добавляет Яндекс к поисковым системам Firefox. В адресной строке движок вызывается ключевым словом `@yandex`.

Из контекстного меню можно искать выделенный текст, ссылку и картинку. Картинка ищется и тогда, когда у неё нет обычного адреса. Кнопка на панели открывает поиск, в том числе в Firefox для Android.

Регион выдачи выбирается в настройках: Россия, Беларусь или Казахстан. Россия и Беларусь открываются на ya.ru, Казахстан — на yandex.kz.

## Что нового

### 1.2.0

- В списке поисковиков движок называется «Яндекс». Пункт меню для выделенного текста скрывается, если Яндекс уже стоит поиском по умолчанию: тот же поиск добавляет сам Firefox.
- Поиск по картинке работает и для изображений без обычного адреса.
- В настройках выбирается регион выдачи: Россия, Беларусь или Казахстан. Для Казахстана поиск открывается на yandex.kz.
- Ссылку можно искать из контекстного меню. Кнопка на панели открывает поиск, в том числе в Firefox для Android.

### 1.1.0

- Поиск выделенного текста из контекстного меню
- Поиск по картинке из контекстного меню
- Поиск открывается на ya.ru вместо yandex.ru, чтобы убрать лишние редиректы
